# WCC Emergency GIS — Data Showcase

An interactive showcase of the [Wellington City Council Emergency Management
GIS datasets](https://github.com/claudecommunity-nz/wcc-emergency-gis-data) —
67 public datasets covering coastal inundation, flooding, active faults,
landslides, and climate projections.

Built and maintained by an autonomous software factory.

## Develop
```bash
bun install
bun run dev
```
Deployed to GitHub Pages from `main` via the `ci` workflow's build.
